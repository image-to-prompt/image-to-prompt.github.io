Before you upload

Limits, privacy, and how to use the result.

What is an image to prompt generator?

It uses a vision model to describe a reference image in text. The result is a starting point for an image generation prompt, not a way to recover the original prompt.

Is this free and how many images can I convert?

The hosted demo is free without signup and currently allows 3 conversions per IP per day. Your own deployment has its own provider costs and limits.

Does it make Midjourney or Stable Diffusion parameters?

No. It returns a general visual description. Add model-specific syntax, aspect ratio, or negative prompts yourself after copying it.

Can I run this open source tool with my credentials?

Yes. The code includes Cloudflare Worker and Docker backends. Put your provider credentials in server-side configuration, never in the public page. Follow the self-hosting guide.

Where does my image go?

The browser uploads it to the configured API for processing. The current backend code does not deliberately save uploaded image files, but your hosting and model provider may process requests under their own policies.
